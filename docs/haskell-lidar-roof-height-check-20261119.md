# Haskell Hall｜2022 北南两条次屋脊的相对高程抽查

按 2024 县正射登记的同一范围和 500×500 网格选点，2025 影像只用于核对选点是否仍对着同一屋顶特征。用 ISGS 的 [表面 DSM](https://data.isgs.illinois.edu/arcgis/rest/services/Elevation/IL_Cook_DSM_2022/ImageServer) 与 [裸地 DTM](https://data.isgs.illinois.edu/arcgis/rest/services/Elevation/IL_Cook_DTM_2022/ImageServer) Get Samples 分别提取相同投影坐标。两服务的元数据均为一美国测量英尺像元、NAVD88 英尺；同坐标相减，再换算米。下列小数是计算留痕，不代表实物精度。

| 部位 | 同坐标 DSM–DTM（米） |
|---|---|
| 北次脊，3 点 | 22.21 / 22.16 / 22.18 |
| 南次脊，3 点 | 22.22 / 22.15 / 22.20 |
| 横山墙屋脊附近，1 点 | 23.70 |
| 两处庭院开阔步道对照 | 接近 0 / 接近 0 |

一处东屋面斜坡的裸地点取值超时，未纳入结论。建筑下的 DTM 是插值地形，不是门槛实测；树冠、屋面投影、铜罩顶尖和像元混合都会限制局部解读。也不能据此确定步道坡度或 Stuart 拱下净空。

C 候选铜罩主体顶约 Z=22.27 m，相对其模型地面，与次脊样本量级接近；没有把局部尖帽高度作为同一特征对比。结合 2024/2025 正射显示长度偏短，下一次先校准平面轮廓和端点，不把屋顶长度差按比例拉高整楼。此提交不更改模型，不代表实际尺寸和游戏通过。
