# 第72栋｜Robie House 复刻 brief

- **对象**：Frederick C. Robie House（美国芝加哥 5757 South Woodlawn Avenue），Frank Lloyd Wright，Frank Lloyd Wright Trust 采用 1910 年完工口径。资产限住宅外壳、主要附属翼、台基、外部台阶、院墙与露台；不复刻室内、景观、游客动线或不可见结构。
- **目标年态**：以官方维护方的现状外观、1963 年 HABS 几何资料互证，避免把测绘当作 1910 原状；瓦面、石帽、墙体和窗带优先，历史变更另标。证据等级：A＝测绘图中明确标注；B＝测绘图图尺读数或实景可见构件；C＝现有模型推定。
- **坐标系**：Blender 世界 X 东、Y 北、Z 上（模型坐标，米）；HABS 列出的北立面、南立面用于定向，不承诺相对测绘真北精确方位。历史主入口与现代游客入口不混用。
- **资料**：[维护方官方实景](https://flwright.org/explore/robie-house)、[修复设计事务所](https://www.harboearch.com/projects/the-ruse-rnga7)、[HABS IL-1005 原始图录](https://www.loc.gov/item/il0039/)、[美国国家公园管理局登记 PDF，13–15 页为所使用的 HABS 图](https://npgallery.nps.gov/GetAsset/620ea545-086b-48b8-b3cb-02011c292dcd/#page=14)。图 13、14 页已实际看图；14 页 SOUTH ELEVATION 为下图，1/8″=1′-0″、有 15 ft 图尺；上图为纵剖，不混用。第 15 页二层平面同时显示朝向，用于辅助定位，不据此声称已锁定入户门位置。
- **构件顺序**：台基→长向南侧主量体和偏东车库翼→低坡连续挑檐→中部退台和烟囱→门窗带/彩玻→露台围墙与石帽。当前屋檐清理版冻结；不因单张旧图或一个相对高差直接改造体量。验收分离：历史准确度、网格/纹理、游戏实测，三者不能互代。

## 独立尺度交叉检查

以 NPS PDF 第14页、200 dpi 栅格（2038×1571）下图南立面量取：图纸顶部烟囱冠线约 y=836 px；其西侧南主檐屋面外沿约 y=1040 px；右下图尺 0→15 ft 约 x=1812→2004 px。换算 (1040−836)/(2004−1812)×4.572≈**4.86 m**（估读 ±0.15 m，包含线宽、像素定位及横图尺用于纵差的潜在扫描误差；不是标注尺寸）。对照资产三档同名构件冠顶与主檐基准：**5.54 / 5.51 / 5.30 m**，分别高于图读约 **0.68 / 0.65 / 0.44 m**。差异真实大于估读误差，但该相对量无法单独区分“烟囱过高”“屋檐过低”或“历史 / 修复状态不一致”。先配第二个独立锚点与官方修复后侧视，再考虑调整，不能直接把烟囱整体压低 0.68 m。来源标注可见于 `HABS_South_Elevation_Datum.jpg`；网格坐标用 `habs_compare.py` 从实际冻结副本读取。

# CS2 逐栋检查与验收口径
2026-11-19，根据本项目实际检查及用户提供的复刻流程参考整理。原资料作为内部参考，不随候选公开。
 
## 区分四件事
1. **离线底稿已查**：源版本锁定，已逐栋确认身份、方向、时代、可用资料与未知项；这不是修复完。
2. **局部已修复并复验**：问题定位到构件/档位，保留旧版本；复查实际导出的 FBX 或源模型，确认预览和数据相符。只说明命中的问题。
3. **实景复刻核准**：建筑外包络、正背侧开间、可见玻璃内层、主要屋顶与基座、入口与上下标高都要有证据。图纸、航拍和实景分别写明测量范围；草模或贴图不冒充实测和实体构件。
4. **可入库／可发布**：实际 Editor 中导入、材质、透明排序、接地、碰撞和 LOD 切换已验证。只在明确的候选或评审分支保留未经实机的成果，不报已放行。

## 二轮优先项
- 先按实景证据判别是隐藏面、真实脱离、背面剔除缺片、必要装配间隙，还是根本轮廓错误。玻璃不当遮挡物，不批量布尔或焊接所有实体。
- 资料读到实际图或照片才计入证据，用同一相机/裁切的前后图；常规及背面剔除并看，透明材质另看透过玻璃可见的内层。
- 建筑需要重构时，先用中文分层轴测或实图标注说明外墙、屋面、门窗、地形和接口，再按有证据的范围重构。没有尺寸就明确是估计。
- 面数预算按建筑类别、可见轮廓和适用标准确定；500 面是此前项目的远景参考，不是全局硬限，加州科学院的专用预算不转用。
- 每项状态使用 待核实 / 已确认 / 已修复 / 已离线复验 / 已撤回；实景与游戏各有独立结论。
