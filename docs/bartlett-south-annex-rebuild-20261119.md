# Bartlett Hall #95B｜南卸货附体重建与离线复验

目标为近年的 Bartlett Hall 外观。本次只改南卸货附体，不拉伸老主楼、改变原点或覆盖 #95 已修的屋脊天窗及东西入口饰带。重现方法：先在锁定的 Git LFS 基线上运行第一轮 bartlett_portal_skylight.py，再运行 [南附体脚本](../scripts/bartlett_south_annex.py)。输出目录需预先创建，不能覆盖源文件或旧候选。脚本在 Blender 4.3.2 实跑，校验源 SHA 或三档几何与 UV 指纹。此草稿只更新脚本及复验记录，不把候选二进制写入普通 Git blobs。

## 尺寸和证据

- [高程、历史航拍及工程文献](bartlett-south-annex-aerial-and-elevation-20261119.md)：1998 未见当前附体、2003 已有；中心平顶的 12 个 DSM–DTM 样点中位约 6.46m；工程报道门洞 7.3152m、石材回边 0.4572m。另取西／东塔各 5 点，约 10.34–10.41 / 10.41–10.49m，候选石帽顶部取 Z=10.38/10.45m。
- 按 FID63 以 0.6204° 配准老主墙；米制，南为负 Y。两侧 X=±9.984m，正面 Y=−39.428m，角塔 X=±7.055→±10.514m、最外南 Y≈−40.00m，老墙 Y≈−29.06m。附体外廓宽约20–21m，南向伸约10–11m（含突出角塔）。Z=0 是模型基座，不是场地绝对高程。
- [现代南面实景](https://www.flickr.com/photos/warrenlemay/54516194850/)用于西侧小门、浅哥特式厚凹口、双塔和石线脚；卸货门顶约4.78m、小门高约2.3m为拟合，非实测。角塔窄缝为外观简化。共享原有自制石材／木门图集，修正跨开口的灰缝与门板纹理；不加入第三方照片像素或任何新贴图。远档省略部分细线脚和门板分缝，保留主体轮廓。
