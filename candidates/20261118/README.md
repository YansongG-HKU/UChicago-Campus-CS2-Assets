## 使用与范围

- `models/` 内 11 个场景压缩包（较大的包按 8 MB 分片）：首轮修复 3 份完整 Blender 场景，第三轮优化 8 份完整场景。使用下列脚本校验全部分片/ZIP/源文件哈希并解压到**尚不存在的新目录**，保留 ZIP 内 `assets/` 路径。

```bash
python candidates/20261118/extract_candidates.py --output ../Campus_Candidates_20261118
```

各场景已内嵌贴图，可独立打开。
- 不是全部 101 源文件，也不是 11 栋独立建筑；组合场景和不同版本分别计数。不要直接覆盖自己的编辑副本。
- `manifest.json` 记录每个模型原路径、字节数、SHA-256、对应 ZIP 及其 SHA-256。
- `fbx-check-only/` 仅供几何核查。首轮 3 个 FBX 是完整场景导出；第三轮 8 个 FBX **只包含被优化的 LOD 网格**，不构成完整可发布资产。7500 结构格式不等于 Autodesk FBX2018 或 CS2 认证。
- `reports/` 保存当时的审查及精修记录；其中“未推送仓库”是当时交付状态，并非本 PR 状态。
- `reopened.json` 是本次提交准备时重新打开全部 11 个 Blender 场景后的对象三角面数与贴图打包状态。
